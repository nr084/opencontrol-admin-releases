# Конфиденциальность — OpenControl Admin 0.1.0

[English](PRIVACY.en.md) · Обновлено 14 октября 2026 г.

Приложение обращается напрямую к заданному вами адресу управления Kerio Control. Логин администратора и пароль передаются этому серверу по HTTPS для входа в API. Последующие запросы используют cookie сессии и CSRF-токен.

Профили, логины и необязательные сохранённые пароли шифруются локально ключом Android Keystore. Резервное копирование и перенос этих данных на другое устройство отключены. Данные активной сессии находятся в памяти. Удаление профиля удаляет его пароль и состояние мониторинга. Удаление приложения удаляет локальное хранилище.

Приложение читает конфигурацию и рабочие данные шлюза: адреса узлов, имена пользователей, интерфейсы и правила. Они отображаются на устройстве. В этой версии нет аналитических SDK, рекламы или отправки телеметрии на сервер разработчика. Фоновые проверки обращаются к настроенным шлюзам; уведомления могут показывать название профиля и статус на экране блокировки в зависимости от настроек Android.

Для подсказки адреса читаются доступные параметры сети Android и, при наличии, provider шлюза OpenControl. Пароль пользователя VPN не запрашивается.

Репозиторий, релизы и публичные обращения размещены на GitHub и регулируются его политиками. Приложение не отправляет обращения автоматически. Не включайте в публичные issue пароли, токены, частные сертификаты, внутренние адреса и персональную информацию.

Документ описывает поведение приложения и не определяет политику журналирования или хранения данных вашего администратора firewall.
