# Начало работы

## Установка

Скачайте `OpenControlAdmin-0.1.0.apk` на [странице релиза](https://github.com/nr084/opencontrol-admin-releases/releases/tag/v0.1.0). При запросе Android разрешите установку из браузера или файлового менеджера. Для проверки загрузки приложен файл SHA-256.

Если раньше была установлена локальная версия с **debug-подписью**, сначала удалите её: Android не допускает обновление с другим сертификатом подписи. Удаление стирает локальные профили и сохранённые пароли. Следующие версии с тем же production-ключом можно устанавливать поверх этой подписанной версии.

Файл `.aab` предназначен для распространения через магазины и не устанавливается как APK. Приложение пока не опубликовано в Google Play.

## Добавление шлюза

На вкладке **Обзор** нажмите **Добавить**. Укажите название, адрес управления, логин администратора и пароль. Можно вставить адрес с окончанием `/admin/`: приложение само приведёт его к пути API. Используется HTTPS, порт по умолчанию — 4081.

При активном VPN приложение может предложить адрес. **Проверьте его перед подключением.** Подсказка строится по доступным параметрам VPN и может быть неверной для другого VPN-клиента или нестандартной подсети. Прямая передача шлюза потребует будущего обновления OpenControl.

Включите **Сохранить пароль**, если хотите хранить его на устройстве. **Сохранить** сохраняет профиль; **Подключить** сохраняет его и открывает соединение.

## Сертификат

Обычный HTTPS проверяется системным хранилищем доверия. Для частного сертификата приложение может запросить подтверждение: сверьте SHA-256 с доверенной копией у администратора. После подтверждения сертификат закрепляется за профилем.

Если закреплённый сертификат изменился, вход блокируется. Независимо проверьте новый сертификат, откройте профиль, выберите **Сбросить доверие сертификату** и подключитесь снова. Не сбрасывайте доверие только ради устранения неожиданного предупреждения.

## Управление

- **Обзор** — профили и сводка по шлюзу.
- **Узлы** — активные устройства, пользовательские сессии и объёмы трафика.
- **Сеть** — интерфейсы, адреса и состояние связи.
- **Правила** — просмотр политики трафика без изменения.
- **Обновить** — загрузить свежий снимок данных.
- **Завершить сессию** — завершить сессию выбранного узла после подтверждения.
- **Выйти** — закрыть административную сессию приложения.

## Работа в фоне

В профиле с сохранённым паролем включите **Фоновая проверка**. На Android 13+ разрешите уведомления. Приложение открывает короткую API-сессию для проверки доступности входа. Уведомление приходит при изменении состояния или первой ошибке, а не после каждой успешной проверки.

Период — примерно 15 минут, но Android может откладывать задания в режиме сна и при ограничениях батареи. Если Kerio доступен только через VPN, VPN должен работать. Принудительная остановка приложения отключает задания до следующего запуска. Мониторинга CPU, порогов трафика и отдельных туннелей в 0.1.0 нет.

## Если что-то не работает

- **Нет соединения:** проверьте VPN, адрес, порт и доступ к интерфейсу управления.
- **Недостаточно прав:** проверьте административные права аккаунта. Разные разделы могут требовать разных разрешений.
- **Сессия истекла:** подключитесь повторно из раздела «Обзор».
- **Нет уведомлений:** проверьте переключатель фоновой проверки, сохранённый пароль и разрешение Android. Время доставки зависит от ОС.
- **Пустой скриншот:** production-сборка защищает окно от захвата. Скриншоты репозитория получены тестовым runner в отдельном эмуляторе с вымышленными данными.

Разработчик не предоставляет корпоративные серверы и аккаунты. Не публикуйте учётные данные и внутреннюю информацию сети в обращениях.
