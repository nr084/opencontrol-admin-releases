# Security / Безопасность

Please do not post credentials, private server addresses or exploit details in public issues. Use GitHub's **Report a vulnerability** option in the Security tab to contact the maintainer privately.

Не публикуйте учётные данные, адреса частных серверов и детали эксплуатации в открытых issue. Для конфиденциального обращения используйте **Report a vulnerability** на вкладке Security.

Version 0.1.0 is an early preview. Keep your firewall and Android device updated. Certificate pinning does not replace independently verifying the fingerprint when trust is first established.

Версия 0.1.0 — ранняя предварительная сборка. Обновляйте firewall и Android. Закрепление сертификата не заменяет независимую проверку его отпечатка при первом подключении.
